# Furniture Showroom Management System

## Overview

A desktop management system developed for furniture showrooms to streamline daily operations including product management, inventory tracking, sales processing, customer management, warehouse monitoring, and business reporting.

The system provides an intuitive JavaFX user interface and integrates with a relational database for secure and efficient data management.

## Features

- Product Management
- Customer Management
- Sales & Invoice Management
- Inventory Tracking
- Warehouse Management
- Employee Management
- Dashboard & Statistics
- Search, Filter, and Sorting
- Database Integration
- Modern JavaFX User Interface

## Technologies Used

- Java 21
- JavaFX
- FXML
- CSS
- JDBC
- MySQL / SQL Server
- DAO Design Pattern
- Scene Builder

## Project Structure

- Dashboard Module
- Product Module
- Customer Module
- Inventory Module
- Warehouse Module
- Sales Module
- Reports Module
